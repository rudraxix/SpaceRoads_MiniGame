# SpaceRoad - MiniGame

**SpaceRoad - MiniGame** is a simple browser-based platformer where the player navigates a spaceship across floating platforms in a neon space environment. The game features progressively scoring, dynamic platforms, and a retro neon aesthetic.

---

## Challenges Faced during the creation of this game using HTML5, CSS and JS

1. Understanding how the Canvas API draws shapes and manages screen refresh.
2.	Managing keyboard input smoothly without lag.
3.	Detecting collisions between the player and platforms.
4.	Ensuring the player resets correctly after falling.
5.	Handling game loops using requestAnimationFrame.
6.	Balancing scroll speed, jump height, and gravity.
7.	Troubleshooting challenges like resetting physics variables properly, fixing collision range etc.

## Features

- Neon-themed graphics with stars in the background
- Smooth platform movement
- Player can jump and move left/right
- Score increments when landing on platforms
- High Score tracking
- Start/Replay button with mouse click or **ENTER key**
- Always spawns the player on a platform

---

## How to Play

1. Open `index.html` in a modern web browser.
2. Press **Start** or **ENTER** to begin.
3. Use the arrow keys:
   - **Left Arrow**: Move left
   - **Right Arrow**: Move right
4. Press **Space** to jump onto platforms.
5. Try to land on as many platforms as possible to increase your score.
6. If you fall off the screen, click **Replay** or press **ENTER** to restart.
